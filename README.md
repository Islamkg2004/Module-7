About This Repository

This repository contains my Python programming assignments from National Louis University.

The purpose of this repository is to organize my Python programs and demonstrate my understanding of programming concepts, problem-solving, and software development.

Each Python file includes comments explaining the program, its purpose, and the code.

Module 5: Lab Activity – Iterative Programming

This module contains five Python programming exercises focused on loops, iteration, and the Turtle graphics library.

Problem 1 – Hello World

A program that uses a loop to print "Hello World" 100 times. A flowchart is also included.

Problem 2 – Numbers and Squares

A program that uses loops to print a list of numbers and calculate the square of each number.

Problem 3 – Regular Polygon

A program that asks the user for the number of sides, side length, line color, and fill color. It uses Python Turtle to draw a regular polygon.

Problem 4 – Divisibility

A program that checks numbers from 1 to 50 and identifies numbers divisible by three, five, or both. A flowchart is also included.

Problem 5 – Turtle Drawing

A creative drawing program using Python Turtle.

Module 7: Lab Activity – Creating and Using Python Functions

This module contains six Python programming exercises focused on functions, lists, mathematical operations, and object-oriented programming.

Problem 1 – Area of a Circle

A function that calculates and returns the area of a circle using the math module.

Problem 2 – Check Range

A function that checks whether a number is within the range from 1 to 10.

Problem 3 – Multiply List

A function that multiplies all numbers in a list and returns the result.

Problem 4 – Unique Elements

A function that creates and returns a new list containing only unique elements from the original list. It uses the append() method.

Problem 5 – Squares

A Python program that uses the provided starter code to create a drawing with Turtle graphics.

Problem 6 – Class Car

A program that demonstrates Python classes, objects, attributes, and methods. The car class includes model, year, color, type, and manufacturer.
